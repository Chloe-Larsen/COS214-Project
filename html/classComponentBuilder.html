Detailed Description

Abstract base class for the Builder pattern over WorkComponent trees.

Defines the common interface for builders that construct concrete WorkComponent products (e.g., Item, ItemGroup). Subclasses implement createProduct() to instantiate the specific product type, and provide fluent configuration methods that return the builder for chaining

Note
This is a "fluent builder": configuration methods in subclasses return the concrete builder type so calls can be chained.
