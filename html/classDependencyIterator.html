Detailed Description

Iterator that traverses a WorkComponent tree in dependency (depth-first) order.

Uses an explicit stack to perform a depth-first traversal of the component hierarchy. Children are pushed in reverse order so that they are visited in their natural order. This iterator yields the root first, followed by its descendants

Note
This iterator does not own the components it traverses; it only references them. Ownership semantics are determined by the WorkComponent tree itself
