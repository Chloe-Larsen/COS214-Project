 {\bfseries{One Engine. Two Industries. Connected Workflows.}}

TIVIDY is a generic Workflow Management System developed in C++11. It provides a reusable engine for creating, managing, assigning, tracking, and processing workflows.

The system demonstrates how a single workflow engine can support different industries without changing its underlying functionality. It includes a command-\/line application and a graphical user interface developed using Qt 5.\hypertarget{md_README_autotoc_md1}{}\doxysection{\texorpdfstring{Team Members}{Team Members}}\label{md_README_autotoc_md1}

TIVIDY demonstrates its functionality through two industry scenarios\+:\hypertarget{md_README_autotoc_md3}{}\doxysubsection{\texorpdfstring{1. Aviation – Aircraft Maintenance Dispatch}{1. Aviation – Aircraft Maintenance Dispatch}}\label{md_README_autotoc_md3}

Both scenarios use the same underlying workflow engine.\hypertarget{md_README_autotoc_md5}{}\doxysection{\texorpdfstring{Features}{Features}}\label{md_README_autotoc_md5}

\begin{DoxyItemize}
\item Create and manage workflow items.
\item Organise tasks into hierarchical groups.
\item Assign tasks to workers.
\item Track task status and progress.
\item Manage task dependencies.
\item Support approvals, rejections, cancellations, and escalations.
\item Apply different assignment and workflow-\/routing strategies.
\item Notify observers when workflow events occur.
\item Integrate with external systems through adapters.
\item Provide a graphical interface using Qt 5.
\item Support both Aviation and Manufacturing workflows.

TIVIDY demonstrates how design patterns can be combined to create a flexible and reusable workflow management engine.

By separating the workflow engine from industry-\/specific scenarios, the system can support different business processes while maintaining the same core functionality.
