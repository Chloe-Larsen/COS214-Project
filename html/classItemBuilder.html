Detailed Description

Concrete builder that constructs and configures an Item.

Supports fluent configuration of an Item's name, priority, deadline, assigned worker, and attached observers (dependencies, notifier and audit logger)

Note
The builder returns ItemBuilder* from chained calls, so users should store the result in an ItemBuilder*
